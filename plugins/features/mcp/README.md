# MCP 服务器

通过 `@modelcontextprotocol/client` 连接 MCP 服务器，将工具注册到 `ctx.ai`。不自行实现 MCP 协议，也不直接调用 pi。插件默认随根配置启用。

## 管理入口

控制台 **AI 设置 → MCP 服务器**，路径 `/admin/mcp/`。需要系统范围的 `admin.console.view` 和 `admin.ai.mcp.manage` 权限；默认授予管理员。

支持添加、编辑、删除、启用、停用、手动重连以及查看工具。编辑时取消勾选“启用此服务器”并保存即可停用。列表按添加顺序显示，每页 20 项，可按名称或描述筛选；筛选仅保留在当前页面，不写入 URL。连接失败仍保存配置，修正后保存或重连即可恢复。

| 字段                   | 用途                                                                                      |
| ---------------------- | ----------------------------------------------------------------------------------------- |
| 名称、描述             | 管理员识别和说明连接                                                                      |
| 激活描述               | 描述模型应在什么情况下使用这组工具，独立持久化；本版不实现工具发现、渐进式披露或 codemode |
| 连接方式               | Local（stdio）、Streamable HTTP 或传统 SSE                                                |
| 自定义请求头           | HTTP 与 SSE 的请求头，包括 SSE 建连和消息发送；Local 可保存，但不发送 HTTP 请求头         |
| 添加前缀以区分同名工具 | 启用后将自定义前缀直接拼接到工具名前，不自动插入分隔符                                    |

Local 在 **Antarestra 所在主机** 启动程序；可执行程序、JSON 字符串数组形式的参数、工作目录、环境变量分别配置。例：程序 `npx`，参数 `["-y", "@modelcontextprotocol/server-filesystem", "/数据目录"]`。带空格的路径作为一个数组元素，无需额外 shell 引号。继承 SDK 默认的基础环境，而非 Antarestra 的全部环境；所需额外变量显式填写。子进程 stderr 不写入 Antarestra 日志，避免外部程序输出凭据。

Streamable HTTP 填写服务提供的 MCP 地址；SSE 填写旧式 SSE 端点。两种远端连接均可配置 `Authorization` 等请求头。本版没有交互式 OAuth 登录界面。

## 工具注册与执行

- 初始化按照持久化的添加顺序连接，后注册的同名工具覆盖先注册者，包括内置普通工具。`use_skill` 仍是 AI 核心的保留名称，不允许占用。
- 两台服务器都提供 `get_files` 时，默认仅最后注册的实现可见。一台配置前缀 `webtools_` 后注册为 `webtools_get_files`，调用仍发送原名 `get_files` 给远端。
- 最终工具名须符合模型通用限制：1–64 个字母、数字、下划线或短横线。列表包含无效、重复或保留名称时整组加载失败，不遗留部分注册；可通过前缀解决保留名称冲突。
- 重连、保存启用配置及 `tools/list_changed` 通知会重新注册该连接的工具，因此会改变当前同名工具的覆盖顺序；服务重启后恢复添加顺序。卸载恢复上一有效实现。
- SDK 负责协议握手、分页枚举及传输；输入 Schema 交由 AI 核心校验。工具调用经过核心的助理能力约束、运行快照、超时和取消机制。正在运行的任务不会切换到后来覆盖的实现；其绑定实现被卸载时，按核心规则取消运行。
- MCP 工具请求超时使用 AI 核心的 `toolTimeoutMs`，默认 600000 毫秒（10 分钟），避免 SDK 默认的 60 秒超时提前终止长任务。修改 AI 核心该配置时，MCP 请求等待时限同步调整；用户取消和连接卸载仍会立即中止等待。
- 外部工具可使用旧版 JSON Schema，由 AI 核心统一迁移为 2020-12 后校验、注册并传给模型；无需为每台 MCP 服务器增加方言适配入口。支持范围与明确拒绝的特殊组合见 [AI 参数 Schema 说明](../../definitions/ai/README.md)。
- 保留文本、嵌入文本资源、资源链接、结构化结果和 `isError`。PNG/JPEG/WebP/GIF 图片转换为运行内临时附件，遵循核心每张 8 MiB、3600 万像素、每次最多 20 张的限制；其他二进制内容返回说明，不向文本上下文塞入 base64。
- 连接与初次工具加载共用 15 秒期限。连接失败或工具列表更新失败会移除本连接工具并显示可重试状态；可点击“重连”。WebUI 卸载不关闭后台连接；MCP 或 AI/数据库依赖卸载时回收注册、请求和子进程。有状态 HTTP 连接关闭时尝试发送 DELETE 终止远端会话，最长等待 1 秒后继续本地清理。

## 数据和访问范围

数据库使用本插件命名空间的 `servers` 表，记录配置、顺序及修订号。修改和删除检查修订号，冲突返回 409。

与现有提供商接入一样，这是管理员维护的系统级共享连接；拥有 `ai.chat.use` 且助理允许相应工具的用户可使用它。会话、运行和临时图片继续按空间隔离，但 MCP 远端账号、进程及其数据并不会自动按 Antarestra 空间隔离。远端权限取决于每台服务器自己的认证与权限设置，不把 `workspaceId` 当成远端授权。本版不提供每用户凭据或每空间独立服务器列表。

请求头和环境变量值当前明文存入服务端数据库，不写入主配置或运行元数据，管理响应仅返回键及 `null`。更新传 `null` 保留已存值、字符串替换值、移除键删除值。界面默认遮罩新值，不向浏览器回传旧值；配置中需要凭据时应放在对应请求头或环境变量中。外部服务可能返回敏感工具结果，调用方仍需按服务自身权限配置。Local 是服务器进程执行能力，不是安全沙箱。

## 接口

所有接口均要求上述两项管理权限，响应使用 `Cache-Control: no-store`：

| 方法   | 路径                     | 用途                                |
| ------ | ------------------------ | ----------------------------------- |
| GET    | `/api/mcp`               | 脱敏配置、连接状态和工具列表        |
| POST   | `/api/mcp`               | 创建连接，服务端生成 ID             |
| PUT    | `/api/mcp/:id`           | 更新配置并重新连接，携带 `revision` |
| POST   | `/api/mcp/:id/reconnect` | 重连已启用服务器，携带 `revision`   |
| DELETE | `/api/mcp/:id`           | 删除配置与工具，携带 `revision`     |

## 验证

`pnpm exec vitest run tests/integration/mcp.test.ts` 启动真实 stdio、Streamable HTTP 和 SSE 测试服务器，以 SQLite 内存数据库验证持久化恢复、鉴权、工具覆盖、前缀、取消及生命周期。包含通过 AI 核心运行工具并生成图片附件的测试，模型驱动为测试替身，不是真实模型集成测试。根目录的 MCP 服务端依赖仅用于这些协议测试；运行插件仅依赖客户端。

开发和构建：`pnpm --filter @antarestra/plugin-mcp dev`、`pnpm --filter @antarestra/plugin-mcp build`。
