# 基本工具

通过主配置 `basic-tools: {}` 加载，依赖 AI 定义插件。默认助理自动获得全部已注册工具；使用明确工具允许列表的 Agent，需要在管理页面勾选对应工具。

- `rename_conversation`：以 `title` 修改当前会话标题，支持 1–200 个字符。
- `todo`：`action: set` 创建或替换列表，`items` 每项包含唯一的 `id`、`text` 与 `status`；`action: update` 使用 `id`、`status` 更新单项；`action: complete_all` 完成整个列表。

状态为 `pending`（待完成）、`in_progress`（进行中）和 `completed`（已完成）。列表最多 100 项，每项内容最多 500 字。单项更新保留其余任务；无效参数、重复标识和未知任务不会改写已有列表。

标题和待办工具通过 AI 核心签发的执行上下文操作当前会话，不能指定其他会话或空间。标题与列表复用 AI 会话数据库持久化及状态推送，修改在核心队列中原子完成。卸载插件回收工具，已保存的列表保留。

聊天页面在输入区上方显示包含未完成项的列表，支持折叠、进度计数和状态文字。全部完成后隐藏，刷新及重新打开会话恢复当前列表；停止或失败不自动完成任务。待办状态属于会话，切换消息分支不会回滚任务进度。

## 日期时间查询

`get_datetime` 无参数调用（`{}`）返回当前时刻，默认使用服务器时区；服务器时区不代表浏览器或用户所在地的时区。查询不会修改会话。

- `datetime`：可选，指定查询的时刻。支持 `YYYY-MM-DD`（按 UTC 零点处理）或带 `Z` / `±HH:mm` 的完整 ISO 日期时间，秒必填，可带 1–3 位毫秒。不接受不存在的日期、无时区的完整时间或自然语言日期。
- `timeZone`：可选，指定输出时区，例如 `Asia/Hong_Kong`、`America/New_York`、`UTC`，默认使用服务器时区。按查询时刻计算夏令时偏移；该参数不改变输入时间的含义。

例如 `{"datetime":"2026-10-03T12:30:00+08:00","timeZone":"Asia/Hong_Kong"}` 返回本地时间 `2026-10-03T12:30:00.000`、偏移 `+08:00` 和 UTC 时间 `2026-10-03T04:30:00.000Z`。

返回字段为 `systemTimeZone`（服务器当前时区）、`timeZone`（目标时区）、`localDateTime`（目标时区日期时间，毫秒精度）、`utcOffset`（该时刻的 UTC 偏移）、`utcDateTime`（UTC ISO 时间）和 `timestampMs`（Unix 毫秒时间戳）。无效日期报 `invalid_datetime`，无效时区报 `invalid_timezone`。
