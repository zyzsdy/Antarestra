# Web 聊天界面

`@antarestra/plugin-chat-webui` 依赖 WebUI、RBAC 与 Server，向 WebUI 注册 `/`，通过 `/api/ai` 接入 AI 核心，不直接依赖具体模型实现或数据库。

进入页面前验证 `chat.webui.view`；AI 接口另外验证 `ai.chat.use`，空间由服务端认证结果解析。未登录跳转登录，身份或空间改变时清空页面状态。客户端不接受任意空间切换。

## 对话与输入

新对话页面选择 Agent，首次发送时创建会话；历史页只显示原 Agent 名称。首条输入的前 30 个字符作为初始标题，之后可以重命名。历史按最近运行活动排序，每次加载 50 项。归档只隐藏记录，在归档列表可查看和恢复；运行期间不能归档。

输入框为 2–16 行，短视口进一步限制高度，超过上限内部滚动。Enter 发送、Shift+Enter 换行，输入法组合输入不会发送。生成中可以编辑下一条草稿，发送按钮变成停止按钮。模型按提供商连接分组，只显示 Agent 允许使用的模型；推理档位来自模型声明，无推理能力时显式发送 `thinking: null`。

模型和思考强度在运行请求被服务端接受后，按用户、工作空间和助理分别保存到当前浏览器。新对话及切换助理时恢复最后使用的设置，刷新页面后仍有效，不跨浏览器同步。尚未发送的选择、被拒绝的请求和浏览历史不会覆盖记录；历史对话仍恢复自身上一轮的设置。保存的模型已不可用时优先回退到助理默认模型，再选择首个可用模型；思考档位失效时优先使用受支持的助理默认档位，再使用首个档位，无推理能力时使用 `null`。存储被禁用或写入失败时退回页面内存。

助理正文通过共享 Markdown 服务渲染；思考和工具记录默认折叠。消息支持编辑和回复分支切换。

## 图片与文件附件

输入框粘贴图片会自动上传，加号菜单可多选任意文件，每条消息最多 20 个附件，也可只发送附件。图片显示缩略图，其他文件显示文件图标与名称胶囊；悬浮或键盘聚焦显示删除按钮，窄屏始终可见。上传中显示进度，可独立取消；上传和删除完成前不能发送。错误保留输入和其他已成功附件，重新选择文件可重试。

文件保存到当前工作空间的 `attachmentDirectory`（默认 `/chat-attachments`），受单文件限制和空间配额约束。同名文件使用随机子目录。待发送附件按会话隔离，刷新页面不保存草稿。删除尚未发送的附件会同步移除工作空间文件并释放配额；删除失败保留预览。发送结果未确认时锁定附件删除，重试复用原幂等请求。恢复已发送消息的附件时，移除草稿引用不会删除原历史文件。

消息历史只记录 workspace-file 的稳定 ID、访问地址、文件名、类型和大小，不持久化 Base64 或临时签名 URL。图片点击打开大图，其他文件点击先打开详情弹窗，再由“下载文件”显式下载。文件清理后显示名称和“文件已过期”；历史过期附件在后续模型上下文中替换为文字提示，新输入中的过期附件要求重新上传。

模型调用时由服务端鉴权读取附件，图片以 Base64 交给 pi-ai。普通文件通过 SDK 的 `onPayload` 转为对应协议：OpenAI Responses 的 `input_file`、Chat Completions 的 `file`、Anthropic 的 PDF `document`、Google 的 `inlineData`；其他可解码 UTF-8 文件发送实际文本内容。OpenAI Responses 的 Word、表格、演示等二进制办公文档通过官方 Files SDK 上传，以 `file_id` 传入，调用结束尽力删除远端副本，并设置一小时自动过期。自定义网关必须支持 Files API，其他接口和不支持的二进制类型明确报错，上传保存不受此限制。依据：[OpenAI 文件输入](https://developers.openai.com/api/docs/guides/file-inputs)。模型还须支持图片模态。AI 单附件读取上限 16 MiB、单次上下文附件总量上限 32 MiB；供应商自身还有模型、格式和大小限制。本地协议转换测试不代表真实模型接入测试。

## 流式回复与恢复

当前会话通过 `?conversation=ID` 定位。输入草稿仅保存在页面内存，切换会话保留，刷新不会持久保存。消息与运行由 AI 核心落库。

SSE 按完整帧解析并依序去重，最终模型消息替换当前请求增量。网络断开后按 0.5/1/2 秒退避续传，仍失败时显示手动重连。重新进入运行中的会话从事件起点重建回复，终态重新读取持久历史。切换页面只断开订阅；停止按钮显式取消服务端运行。

发送结果不确定时保留原幂等命令，重试不会重复启动同一轮。失败、取消和服务重启保留部分回复；可以重试本轮（工具可能再次执行），或者回到上一完整轮次，保留旧分支并将原输入恢复到空草稿。后者不会删除中断记录，但当前页面不提供完整分支浏览器。

## 前端与验证

使用 Vue SFC 与 `@antarestra/webui/vite`，复用共享 Vue、Reka UI、API、选择框、编辑弹窗和反馈。业务状态在 `useChat.ts`，SSE 解析及投影在 `stream.ts`，CSS 统一以 `chat-` 前缀隔离，支持挂载到 body 的弹层。

客户端测试覆盖分帧、中文解码、重复事件、最终消息替换、草稿隔离、迟到响应与幂等发送；AI 集成测试使用实际 SQLite 和可控模型驱动验证历史管理及授权，不等同于真实模型验证。
