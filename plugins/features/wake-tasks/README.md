# 定时唤醒任务

`@antarestra/plugin-wake-tasks` 提供持久化 AI 定时任务，默认配置已启用 `wake-tasks: {}`。复用主数据库的命名空间、迁移与查询服务，支持 SQLite、PostgreSQL、MySQL，不需要独立任务队列服务。

## AI 工具

- `wake_task_create`：创建任务。`triggerAt` 为带时区的未来 ISO 8601 时间；`reason` 为触发原因；`prompt` 为触发时完整的用户输入，三者必填。`mode` 默认 `once`，只执行一次；设为 `interval` 时必须填写 `intervalSeconds`，范围为 60 至 31536000 整数秒。一次性任务不能携带周期参数。
- `wake_task_list`：仅列出当前空间的任务，包含状态、首次时间、下次时间、最近执行会话、运行及错误。默认每页 20 项，最多 100 项；返回 `nextCursor` 时将其作为下一页的 `after`，不使用大偏移量分页。
- `wake_task_cancel`：按任务 ID 取消当前空间未结束的任务；正在执行的运行在下一次租约检查时取消，已产生的外部效果不会撤销。

示例参数（实际调用时须使用未来时间）：

```json
{
  "triggerAt": "2030-10-04T09:00:00+08:00",
  "mode": "interval",
  "intervalSeconds": 86400,
  "reason": "每天检查项目进度",
  "prompt": "检查当前工作空间中的项目进度，汇总已完成事项、阻塞问题和下一步建议。"
}
```

一次性任务省略 `mode` 和 `intervalSeconds`。固定秒数周期不等于按日历时区的夏令时规则重复；当前不支持 Cron 表达式。需要调整任务时先取消，再创建新任务。

自动使用当前有效工具上下文关联原工作空间、发起人、来源会话、助理和身份提供者，模型不能指定或替换这些关联。每次唤醒在原空间为原助理创建独立新会话，将 `prompt` 原文传入 `UserInput.text`。新运行采用该助理执行时的配置快照，不复制原会话历史；提示词应包含完成任务所需的信息。触发原因用于任务记录及新会话标题。

默认助理自动获得已注册工具；限制工具范围的自定义助理需显式启用上述工具。执行结果保存在新会话中，可从会话列表或任务最近执行会话中查看。本插件不额外提供通知推送或管理页面。

## 调度与恢复

```yaml
wake-tasks:
  pollIntervalMs: 1000
  batchSize: 20
  concurrency: 4
  leaseMs: 60000
```

启动立即检查到期任务，随后定期读库；工作槽释放后继续检查。每次分别按 `(status, available_at, id)` 复合索引读取到期等待任务和过期租约，每类最多取 `min(batchSize, 剩余并发容量)` 项，再按到期顺序领取。不会完整加载所有任务，也不会为每个未来任务建立内存计时器。查询列表使用 `(workspace_id, id)` 索引与游标。

数据库条件更新领取任务并生成独立租约令牌；执行期间定期续租，状态更新必须匹配当前令牌，避免过期执行者覆盖新状态。并发上限按调度实例计算，同一任务不会在本实例内重叠执行。默认触发延迟约为轮询间隔；并发已满时等待空闲槽。

每个触发轮次提前持久化独立会话 ID，并复用 AI 核心的运行幂等键。因此建会话或启动运行之后、调度确认之前中断，恢复时仍使用同一会话与运行。临时服务或数据库故障按指数退避重试，最长等待 60 秒；插件卸载取消活动运行并回收轮询，租约到期后由重新加载的服务恢复处理。

一次性运行成功记为 `completed`，模型运行失败或取消记为 `failed`，不自动重复提交已经执行的用户输入。周期任务在本轮结束后推进到未来最近一次时间，以原计划时间为锚点；停机或执行过久漏过多次时只补执行一次，跳过其余积压，不会集中补跑。周期运行失败会保留错误，并继续下一周期。取消任务或身份失效会停止后续触发。

这保证的是持久化调度与同一轮次的幂等提交，不承诺模型调用外部系统的副作用“恰好一次”。进程崩溃后的 AI 中断运行由核心标记失败，任务保留其运行和会话以便检查。

## 后台身份与生命周期

不保存 Cookie、访问令牌或登录会话，也不借用系统管理员身份。创建和执行时经由原入口的 `RequestSourceProvider.resolveBackground(actorId, workspaceId)` 重新确认身份及 `ai.chat.use` 权限，固定原提供者以避免初始化加载顺序导致误判。提供者暂不可用会重试；账号、空间或权限失效会记录失败。

本地认证已实现后台身份解析：仅允许发起人的个人空间，重新检查提供者、身份、账号状态和当前默认角色，登录过期或退出不影响已授权的后台任务。其他入口需要实现同一后台解析接口；未支持的入口无法创建任务。

数据库作用域由本插件持有；AI 运行持久化归 AI 核心持有，因此单独卸载定时任务插件仍能保存运行取消状态。当前项目 AI 核心采用单节点运行管理；租约防止调度重复领取不代表整个 AI 核心已支持多节点部署。

## 验证

`pnpm exec vitest run tests/integration/wake-tasks.test.ts tests/integration/ai.test.ts tests/integration/rbac.test.ts` 覆盖文件数据库重启恢复、一次性与周期执行、竞争领取、并发容量、幂等交接、错误重试、空间隔离、账号撤销、取消、卸载及依赖恢复。

可设置 `ANTARESTRA_TEST_WAKE_POSTGRES` 指向独立测试库，运行同一测试文件中的 PostgreSQL 用例。测试使用演示模型驱动，不需要真实模型密钥，不等同于真实模型集成验证。
