# 全局表情包库与群 bot 管理员验证

## 实现范围

- `im-stickers-lib` 提供图片列表、上传、元数据编辑、删除、查询、`{{ im_stickers }}` 和 `/sticker add/delete`。已加入主配置和 server 依赖。
- workspace-file 以所属插件登记的精确文件 ID 提供共享读取；普通目录、路径与写操作继续隔离。表情包复制到专用空间，避免群归档清理影响使用。删除先撤销共享，再持久重试存储清理。
- im-commands 增加普通用户和 bot 管理员两类指令，以及每群独立的持久管理员名单。群主自动授权，其他平台管理员不自动授权；`/admin add <id>` 可添加本群额外管理员。
- 管理员编辑入口位于“群消息与 AI 会话”的各群操作栏，使用独立管理权限和修订冲突保护；不放入 IM 接入页。
