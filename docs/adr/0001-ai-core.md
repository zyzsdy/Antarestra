# 统一 AI 核心与可分支历史

AI 注册、运行协调、历史及 HTTP 接口统一由 `@antarestra/ai` 提供，替代早期分别建立 Agent、LLM、工具和会话定义插件的方向。执行循环与模型协议仍通过独立后端/驱动适配，保留 `agent-pi` 与 `llm-pi` 的独立实现边界，避免核心绑定 pi 类型。

历史采用追加消息分支，重新生成从用户输入重跑整轮，保留旧工具记录而不复用其结果。这使每条分支的上下文保持独立，但有副作用的工具可能再次执行；取消不承诺撤销工具已经产生的副作用。

工具允许覆盖，并以注册栈恢复上一有效实现；Run 固定注册实例，覆盖不影响已开始的运行，卸载其绑定实现则取消运行。其他能力仍拒绝同名注册，`use_skill` 专属于唯一 Skill 服务。

插件间扩展使用 Cordis 原生串行转换和并行通知，持久事件负责 SSE 重放。首版限制单进程部署，采用数据库游标轮询避免内存队列和重放切换竞态；通知不承担数据恢复职责。
